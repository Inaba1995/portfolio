# Сайт-портфолио Nikita Semenenko

Одностраничный сайт-портфолио для ниши «малый бизнес и эксперты»: лендинги, чат-боты, MVP и поддержка. Собран по ТЗ из [`TZ.md`](TZ.md).

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Или просто открыть `index.html` в браузере — сайт статический, без сборки.

## Структура

```
portfolio/
├── index.html              # разметка и тексты
├── TZ.md                   # техническое задание
├── assets/
│   ├── css/style.css       # стили и адаптив
│   ├── js/app.js           # меню, reveal, форма → Telegram
│   └── cases/              # изображения кейсов
└── screenshots/            # скриншоты для рабочей тетради
```

## Что реализовано

- Адаптив 360–1440 px, мобильное меню.
- Секции: hero, боли, услуги, кейсы, обо мне, процесс, пакеты, FAQ, контакты.
- Форма собирает имя, задачу и описание → открывает Telegram с готовым сообщением.
- FAQ на `<details>` работает без JS.
- Анимации появления с `prefers-reduced-motion`.
- SEO: title, description, Open Graph, favicon.
- Без внешних шрифтов и CDN.

## Контакты

Перед публикацией заменить `{{TELEGRAM}}` и `{{EMAIL}}` в `index.html` и `assets/js/app.js` на реальные.
